# 도트·디자인 인수인계

재미 개선(`docs/fun-improvements.md`)에서 **로직은 모두 들어갔고 그림만 비어 있다.** 이 문서는 그 그림을 이어서 만드는 사람(Opus)이
코드를 처음부터 뒤지지 않고 바로 시작하도록 쓴 것이다. 그림을 끼워도 서버·번역·규칙은 건드리지 않는다.

## 1. 먼저 읽을 것

- `docs/product.md`의 **Buddy** 절: 캐릭터(말랑이), 그림 원칙, 무대 동작, 디자인 톤.
- `docs/fun-improvements.md`: 무엇이 왜 들어갔는지. 이 문서는 그중 **그림이 필요한 곳만** 다룬다.
- `CLAUDE.md`의 Principles와 Git workflow(브랜치 `dev`, 커밋 전 `pnpm check`, 한국어 커밋 메시지).

## 2. 지켜야 할 것

- **오리지널.** Pokémon·Tamagotchi·Digimon의 이름, 이미지, 특정 캐릭터를 떠올리게 하는 실루엣을 쓰지 않는다. 달걀형·원형 기기
  테두리나 기기 버튼 줄 배치도 피한다(`product.md` 원칙).
- **말랑이는 한 종류.** 몸(동그란 떡)과 얼굴 위치는 그대로 두고, 직업·표정·소품은 **얹는** 방식으로 만든다. 모든 동작이 같은 얼굴로 보이는
  일관성이 가장 중요하다.
- **도트 스타일.** 작은 격자, 적은 색, 굵은 외곽선(`k`), 머리가 큰 비율, 프레임을 뚝뚝 넘기는 움직임. 귀엽고 올드하지 않게(GitAnimals 참고).
- **정신없지 않게.** 무대는 채팅 위 1/3이고 채팅이 핵심이다. 벽 장식(깃발, 계절 장식)은 정신없어서 뺀 적이 있으니 새로 걸지 않는다.
  계절 모습은 **버디 몸에만** 쓴다.
- **게임이 아니다.** 직업 때문에 숫자나 능력이 달라지지 않는다. 차이는 모습·행동·대사뿐이다.
- 문자열 격자는 **모든 행의 길이가 같아야** 하고, 격자 배열에는 `// prettier-ignore`를 붙여 모양을 유지한다.

## 3. 코드 지도

| 무엇 | 어디 |
| --- | --- |
| 도트 그리기(문자열 격자 → SVG 사각형) | `app/src/features/buddy/pixel/pixel-sprite.tsx` (`Frame`, `Palette`, `PixelSprite`) |
| 말랑이 격자와 자세, 소품 격자, 팔레트 | `app/src/features/buddy/pixel/sprites.ts` |
| 무대(자세 고르기, 소품, 움직임, 말풍선) | `app/src/features/buddy/components/buddy-stage.tsx` |
| 무대 꾸미기(화분, 밥그릇, 러그, 액자) | `app/src/features/buddy/components/stage-decor.tsx` |
| 직업 이모지(글자 화면용)와 순서 | `app/src/features/buddy/jobs.ts` (`JOB_ICON`, `JOB_ORDER`) |
| 직업 소품·배지(무대) | `app/src/features/buddy/pixel/sprites.ts` (`JOB_PROPS`) |
| 직업 대사, 말풍선 | `app/src/features/buddy/use-buddy-talk.ts` (`JOB_LINES`), 문구는 `app/src/i18n/locales/*.json`의 `buddy.say.*` |
| 아바타(상세·로그인 화면) | `app/src/features/buddy/components/buddy-avatar.tsx` (`buddyFrame(stage, 'idle')`) |

`sprites.ts`의 구조:

- `BABY`(16×16), `CHILD`(20×20), `ADULT`(24×24)가 단계별 기본 격자다. 알(`EGG`, 16×16)은 따로 있다.
- `ANATOMY`가 단계마다 **눈·입·발 위치**를 적어 둔다. `makePoses`가 기본 격자에 눈·입·발만 바꿔 자세를 만든다
  (`Pose` = idle / step / blink / happy / sleep / hungry / eat / strain / laugh / worried / yawn / hiccup / surprised). 그래서 모든 자세가
  같은 얼굴이다. 볼 위치(`cheeks`)도 적어 두어 볼을 물들이는 표정(딸꾹질)에 쓴다.
- 얹기 도구: `paint(frame, [[row, col, key], ...])`가 격자 위에 픽셀을 덮어쓴다.
- 팔레트: 말랑이는 `BUDDY_PALETTE`(k 외곽선, b 몸, l 하이라이트, s 그늘, p 볼, g/G 잎, f 꽃잎, y 꽃술, m 벌린 입 안), 소품은 `PROP_PALETTE`
  (k, c/h 똥, w 흰색, a 그릇, r 하트, y 반짝이, u 레벨업, g/G 식물, o 화분, m/n 러그, f 꽃, S 은, Y 금, e 화분 테두리, B 유약 화분).
  새 색은 **쓰이지 않은 글자**로 추가한다.
- 무대 크기: 한 픽셀을 `gridScale`(3~5pt)로 그린다. 소품은 `PROP_SCALE = 3`. 어른 격자의 높이를 24에서 바꾸면 이 계산과 걷는 범위
  (`minX`/`maxX`)에 영향이 가니, **격자 크기는 24×24를 유지**하고 그 안의 빈 칸에 얹는 것을 권한다.

## 4. 바로 보는 법

```bash
pnpm web
```

- `http://localhost:8083/preview` — **그림 확인용 화면**(개발 빌드에서만 열린다). 단계(EGG~ADULT), 직업, 동작(`job work`, 춤, 노래, 딸꾹질·깜짝·두리번·하품),
  채팅 낱말 반응(웃음·사랑·잘자·응원·위로·아침), 방의 사건(밥·청소·똥·레벨업·진화·함께·같이 있음), 상태(배고픔, 똥), 상대가 쓰다듬기를
  버튼으로 바로 일으킨다. 그림을 끼우고 이 화면에서 직업을 바꿔 가며 본다. 맨 아래 **poses**는 고른 단계의 모든 자세를 멈춘 채
  크게 나란히 보여줘 얼굴을 한눈에 비교한다. 파일: `app/src/app/preview.tsx`.
- `http://localhost:8083/demo` — 구경하기 전체 흐름(어른이 되면 요리사).
- 화면이 반영되지 않으면 Metro 캐시: `pnpm start --clear`.
- 한국 시간으로 밤(23~7시)에는 무대의 버디가 자는 모습이다(라디오 DJ는 3~11시). 미리보기에서 동작을 눌러도 Zzz가 뜰 수 있다.

## 6. 직업별 시안

직업·점수·변경 규칙은 `docs/fun-improvements.md` 5·6절. 아래는 그림 쪽 힌트일 뿐이니 더 나은 안이 있으면 바꿔도 된다.
직업은 **두 사람이 쓰는 앱에 어울리는 어른스러운 느낌**(동네 가게, 라디오, 정원, 책상)으로 정했다(2026-10-15에 유치하다는 이유로 이름을 바꿈). 만화 같은 과장된 소품(왕관, 망토, 큰 어깨띠)은 피하고 작고 담백하게 그린다. 코드의 id는 `CHEF`·`GARDENER`·`DJ`·`POET`·`BARISTA`(코미디언 `COMEDIAN`은 2026-10-15에 뺐다).

| 직업 | 일하는 모습(A) | 소품(B) | 모습(C) | 말풍선 예 |
| --- | --- | --- | --- | --- |
| 요리사 `CHEF` | 조리대 뒤에서 냄비를 젓는다(몸이 좌우로 살짝) | 냄비·프라이팬에서 김 | 꽃을 가리지 않는 작은 요리사 모자 또는 앞치마 | "보글보글", "간 좀 봐줄래?" |
| 정원사 `GARDENER` | 큰 식물 옆에서 물뿌리개로 물을 준다 | 물뿌리개, 작은 화분과 잎사귀 | 밀짚모자나 앞치마(꽃을 가리지 않게) | "오늘도 잘 자랐네", "물 줄 시간이야" |
| 라디오 DJ `DJ` | 방송 책상 뒤에서 음악에 맞춰 고개를 끄덕인다 | 마이크, 음표(머리 위) | 헤드폰(귀에 얹는다) | "지금은 새벽 두 시", "다음 곡은 뭘로 할까" |
| 시인 `POET` | 나무 책상 뒤에서 편지·시를 쓴다(웃는 얼굴 + 하트) | 깃펜과 편지, 하트(머리 위) | 작은 베레모나 목에 두른 스카프 | "편지 쓰는 중…", "오늘 문장 하나 건졌어" |
| 바리스타 `BARISTA` | 카페 카운터 뒤에서 커피를 내리며 말을 건다 | 김이 나는 커피잔 | 작은 앞치마 | "오늘 하루 어땠어?", "천천히 말해도 돼" |

- 일하는 동작은 `ACT_MS.job = 2000`ms 동안이고, 프레임은 `TICK_MS = 450`ms마다 바뀐다(한 번에 4프레임 안팎).
- 일하는 동안 말풍선으로 `JOB_LINES`의 대사를 하나 말한다(어린이부터 말하지만 직업은 어른만 있다).
- 직업이 바뀌면 무대가 바로 바뀌어야 한다(`BuddyView.job`이 바뀌어 다시 그려진다). 미리보기에서 직업 칩을 눌러 확인한다.

## 7. 직업별로 이미 달라진 것 (그림이 아니어도 됨)

그림이 없어도 동작하는 차이다. 그림을 끼울 때 이 동작을 깨지 않는다.

| 직업 | 차이 |
| --- | --- |
| 요리사 | 밥 먹은 뒤 "간이 딱 맞네"(`chefFed`), 혼자 있을 때 폴짝거리며 요리 |
| 정원사 | 치운 뒤 "말끔하네"(`gardenerCleaned`), 혼자 있을 때 식물을 가꾼다 |
| 라디오 DJ | 자는 시간이 3~11시(보통 23~7시) |
| 시인 | 사랑 낱말에 큰 하트와 "나도, 그래"(`poetLove`) |
| 바리스타 | 말풍선이 0.6배 간격으로 나오고, 대화 중에도 한마디씩 거든다 |

## 8. 끝났다고 보는 기준

- [ ] 어른 직업 5개가 `/preview`에서 각각 일하는 자세·소품·모습으로 보인다(이모지가 무대에서 사라진다).
- [ ] 어떤 자세·직업이어도 **같은 말랑이 얼굴**로 보인다(눈·입·볼·꽃 위치).
- [ ] 격자 행 길이가 모두 같고, 격자 배열마다 `// prettier-ignore`가 있다. 새 색은 새 글자다.
- [ ] 아기·어린이·알은 그대로이고, 아바타(`buddy-avatar.tsx`)와 구경하기가 깨지지 않는다.
- [ ] 라이트·다크 모드에서 모두 잘 보인다(무대 배경 `colors.stage`가 다르다).
- [ ] `pnpm check`가 통과한다. 번역 키를 더했으면 `ja`/`ko`/`en` 세 파일의 키가 같다.
- [ ] 이 문서의 5절 표와 `docs/fun-improvements.md`의 상태를 끝난 만큼 고친다.

## 9. 하지 않는 것

- 직업·점수·변경 규칙(서버 `BuddyJob`, `BuddyService.changeJob`)과 경험치 규칙을 바꾸지 않는다.
- 새 라이브러리를 넣지 않는다(비트맵 이미지도 쓰지 않는다. 도트는 문자열 격자 → SVG).
- 이모지가 글자 화면(대화 카드, 상세, 앨범)에서 쓰이는 것을 지우지 않는다.
